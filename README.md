# Pinterest Download Bot

Личный Telegram-бот на **Cloudflare Workers**. Отправляешь ссылку Pinterest или `pin.it` — получаешь MP4 со звуком. Без обязательных подписок, рекламы и постоянно включённого ПК.

Бот сохраняет байты исходного MP4, не перекодирует его и не уменьшает качество. Максимум **49 МБ**. При наличии нескольких опубликованных MP4 выбирается вариант с наибольшим разрешением. Только HLS, закрытые пины и встроенные ролики сторонних видеохостингов не поддерживаются: бот прямо сообщает причину.

## Что нужно

- Аккаунт Cloudflare с Workers и D1.
- Telegram-бот: в [@BotFather](https://t.me/BotFather) отправить `/newbot`, выбрать название и username, получить токен.
- Твой числовой Telegram user ID. Можно узнать через `getUpdates` своего бота **до подключения webhook**: отправить ему сообщение, вызвать Telegram Bot API методом `getUpdates` и посмотреть `message.from.id`. Не публиковать URL с токеном. При необходимости используй знакомого бота для определения ID.
- [Node.js](https://nodejs.org/) **24 или новее** и Git на Windows.

## Установка через терминал Windows

Открой PowerShell и выполни:

```powershell
git clone https://github.com/76vtky2qg7-byte/pinterest_download_bot.git
cd pinterest_download_bot
npm ci
npx wrangler login
npx wrangler d1 create pinterest-bot --binding DB --update-config
npx wrangler d1 migrations apply DB --remote
npm run deploy
```

Создание D1 добавит **реальный** `database_id` в `wrangler.jsonc`. Если Wrangler спрашивает подтверждение обновления конфигурации, согласись. Если база `pinterest-bot` уже существует, используй её binding `DB` и настоящий ID в конфигурации вместо создания второй базы.

Далее сохрани три переменные. Каждая команда отдельно попросит значение:

```powershell
npx wrangler secret put BOT_TOKEN
npx wrangler secret put WEBHOOK_SECRET
npx wrangler secret put ALLOWED_USER_ID
```

- `BOT_TOKEN`: токен из BotFather.
- `WEBHOOK_SECRET`: случайная строка из 32–256 латинских букв, цифр, `_` или `-`. Сгенерировать можно в PowerShell командой `[guid]::NewGuid().ToString('N')`. Сохрани значение, оно ещё потребуется при подключении webhook.
- `ALLOWED_USER_ID`: только твой числовой ID, без пробелов и без `@username`.

Секреты не записываются в исходники. До настройки всех переменных и binding `DB` Worker отвечает `503 Bot not configured`, поэтому случайно открытый бот не начинает скачивать для посторонних.

Адрес Worker появится в выводе `deploy`, например в домене `workers.dev`. Подключи Telegram:

```powershell
npm run setup:webhook
```

Скрипт спросит адрес Worker, токен BotFather и тот же `WEBHOOK_SECRET`. Ввод токена и секрета скрыт. Он проверит готовность Worker, подключит webhook, задаст команды и покажет ссылку на твоего бота. Значения также можно передать через переменные окружения `BOT_URL`, `BOT_TOKEN`, `WEBHOOK_SECRET`.

## Как пользоваться

1. Открыть своего бота и отправить `/start`.
2. В Pinterest выбрать видео → «Поделиться» → «Копировать ссылку».
3. Отправить ссылку боту. После загрузки он пришлёт воспроизводимый MP4.
4. На iPhone открыть видео в Telegram → меню «Поделиться» → сохранить видео.

Бот работает только в личном чате с владельцем. Чужие пользователи и группы игнорируются. `/help` показывает ограничения.

## Проверки

```powershell
npm test
npm run check
npm run check:video -- https://pin.it/15s01XzaL sample.mp4
```

Последняя команда проверяет реальный Pinterest из сети твоего компьютера и сохраняет файл. Она не проверяет отправку Telegram или доступ с IP Cloudflare. Для окончательной проверки отправь эту ссылку боту после запуска и проверь MP4 со звуком.

На 2026-10-01 пример `15s01XzaL` скачивался напрямую: H.264/AAC, 720×1280, 16,879 секунды, 3 208 946 байт. Сохранённый файл и токены не включены в репозиторий.

## Если не работает

- `/health` возвращает `503`: не настроены DB или секреты.
- Telegram не отвечает: проверь webhook командой `npm run setup:webhook`, ID владельца и журнал `npx wrangler tail`.
- Pinterest возвращает ошибку или не предоставляет MP4: бот сообщает это; он не заменяет видео заглушкой и не выдумывает ссылку на файл.
- Нет результата за 45 секунд: запрос прерывается. Если видео не пришло, отправь ссылку **новым сообщением**.
- Нельзя гарантировать, что Pinterest одинаково доступен с домашней сети и IP Cloudflare. Проверка после развёртывания обязательна.

Повтор одного Telegram `update_id` не запускает новую загрузку: D1 атомарно сохраняет состояние `processing`, `done` или `failed`. После сетевого разрыва видео могло уже отправиться, поэтому бот не делает автоматическую повторную отправку. При аварии Worker запись может остаться `processing`; новое сообщение с той же ссылкой обрабатывается отдельно. История старше семи дней удаляется автоматически при последующих запросах.

Загрузка идёт потоком без помещения полного видео в память Worker. В D1 сохраняются ID запроса, время, статус и код ошибки; тексты сообщений, ссылки и токены не сохраняются.

## Обновление

```powershell
git pull
npm ci
npm test
npm run deploy
```

Изменённую после создания D1 конфигурацию сохрани в своей копии. Секреты Cloudflare сохраняются при последующих deploy. Для отдельной тестовой копии задавай своё имя Worker и отдельную D1 базу, чтобы не затронуть рабочий webhook.
