# Pinterest Download Bot — проектирование
Дата: 2026-10-01

## Цель
Личный Telegram-бот на Cloudflare Workers. Пользователь отправляет ссылку Pinterest, бот возвращает доступный MP4 со звуком. Никакой рекламы, обязательных подписок, платежей, заглушек или скрытого снижения качества. Компьютер пользователя не требуется.

## Согласованные условия
Репозиторий: 76vtky2qg7-byte/pinterest_download_bot.
Платформа: Cloudflare Workers.
Доступ: только Telegram user ID владельца, заданный в конфигурации.
Ссылки: pin.it и страницы отдельных пинов Pinterest, включая региональные домены и ссылки «Поделиться».

## Архитектура
Один JavaScript Worker получает Telegram webhook по HTTPS. Cloudflare D1 хранит идентификаторы принятых update_id и состояние обработки, чтобы повторная доставка Telegram не запускала тот же запрос заново.
Worker проверяет webhook secret, личный чат и ID владельца. Команды /start и /help объясняют отправку ссылки.
Короткая ссылка раскрывается ограниченной цепочкой перенаправлений. Разрешены только точные домены Pinterest и pin.it; произвольные адреса не скачиваются.
Из ссылки извлекается ID пина, рекламные и пользовательские параметры удаляются. Загружается каноническая страница этого пина.
Из структурированной разметки VideoObject извлекается contentUrl. Поддерживаются опубликованные списки videoList/video_list, если они находятся в данных именно этого пина. Видео из блока рекомендаций выбирать запрещено.
Выбирается MP4 с наибольшим доступным разрешением среди явно опубликованных вариантов. Ссылки на файлы разрешены только с HTTPS CDN pinimg.com.
Worker отправляет MP4 методом sendVideo через потоковый multipart upload. Файл не перекодируется и полностью в памяти не собирается. Максимальный размер — 50 МБ, с запасом относительно лимита Telegram. Лимит проверяется по заголовку и по фактически прочитанным байтам.
Webhook обрабатывается в пределах явного общего таймаута. Повторная доставка уже принятого update_id получает успешный ответ без повторного запуска. Владелец может повторить запрос новым сообщением. Автоматического гарантированного повтора после аварии нет.
После доставки сохраняется состояние done. При ошибке — failed и безопасная диагностическая информация без токенов.

## Ошибки и границы
Неверная ссылка, удалённый/закрытый пин, отсутствие MP4, только HLS, внешний видеохостинг, превышение размера, таймаут, HTTP-ошибка Pinterest или Telegram сообщаются прямо.
HLS нельзя выдавать за MP4, URL файла нельзя выдумывать заменой расширения. Перекодирование, обход CAPTCHA, доступ к закрытым пинам и загрузка сторонних сайтов не входят в первую версию.
При неоднозначном результате отправки Telegram после разрыва соединения не обещать доставку и не повторять её автоматически.
Доступность отдельных пинов зависит от ответа Pinterest на запросы Cloudflare.

## Конфигурация и поставка
BOT_TOKEN и WEBHOOK_SECRET — только Cloudflare secrets, не GitHub.
ALLOWED_USER_ID — обязательная конфигурация владельца.
D1 binding — DB. В репозитории: код Worker, SQL-миграция, wrangler.jsonc, package.json, инструкция на русском, настройка webhook и проверки.
Публикация кода в этот репозиторий разрешена пользователем. Развёртывание требует доступа к Cloudflare и токена созданного Telegram-бота; они сейчас не предоставлены.

## Проверки
Проверить разбор обычных/коротких ссылок, границы доменов и перенаправлений, выбор нужного видео, отсутствие MP4, сохранение звука и байтов, ограничение размера, отказ чужим пользователям, неверный webhook secret и повторный update_id.
Повторить реальное скачивание указанного примера кодом проекта.
После развёртывания проверить: ссылка в Telegram → доставленный воспроизводимый MP4. До этого не заявлять о работающем развёрнутом боте.
