# Проверка реализации

Дата: 2026-10-01.

- `npm test`: 18 проверок, 18 успешно.
- `npm run check`: Wrangler 4.145.0 успешно собирает Worker (dry-run). D1 binding добавляется командой создания базы при настройке, его ID не выдуман.
- `node --use-env-proxy scripts/check-video.mjs https://pin.it/15s01XzaL /tmp/pinterest_project_sample.mp4`: реальный ролик скачан кодом проекта, 3 208 946 байт.
- `ffprobe`: видео H.264 720×1280, звук AAC, 16,879002 секунды.
- После исправлений окончательный extractor повторно проверен на полученной реальной HTML-странице: выбран тот же подтверждённый MP4.
- Независимая проверка кода выявила две ошибки: неверную передачу ExecutionContext в функцию загрузки и возможность выбрать вложенное рекомендованное видео. Для обеих добавлены регрессионные тесты, воспроизведён провал, внесены исправления, вся серия проверок прошла.

Тесты используют реальные Web Streams и SQLite с миграцией проекта. Ответы внешних Pinterest/Telegram изолированы на сетевой границе тестов; производственный код не содержит тестовых подмен.

## Принятые решения

- Пользователь «всё создавай» разрешил реализацию и запись в указанный репозиторий без дополнительных согласований плана.
- D1 ID добавляется автоматически при создании базы. Пока binding и секреты отсутствуют, Worker явно сообщает, что не настроен. Стоимость ошибки настройки: бот не запустится, а не откроется для посторонних.
- У dedicated VideoObject Pinterest может быть ID исходного пина, отличающийся от ID репина. Используется только специальная разметка основного видео страницы. Произвольные VideoObject рекомендаций не принимаются. Если Pinterest изменит эту разметку, извлечение может перестать работать и потребует обновления.
- Размер ограничен 49 000 000 байт с запасом к лимиту Telegram 50 МБ. Более крупный ролик отклоняется без скрытого уменьшения качества.
- Метаданные размеров Pinterest иногда относятся к исходной загрузке: размеры файла не передаются в sendVideo, Telegram определяет их по MP4.

## Что ещё не проверено

Развёртывание в пользовательском аккаунте Cloudflare, доступ Pinterest с его Worker, регистрация webhook и реальная доставка Telegram. Для этого нужны настройка D1, три секретные переменные и созданный Telegram-бот. Успешный dry-run не заменяет эти проверки.

HLS и сторонние видеохостинги исключены из согласованной первой версии. Автоматической повторной отправки после неоднозначного сетевого сбоя нет: требуется новое сообщение владельца.
